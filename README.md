# SPACE BATTLESHIP ODYSSEY

宇宙戦艦を操作して、激しい弾幕をかいくぐる本格派SF弾道アクションゲームです。
HTML5 Canvasを使用した滑らかな描画と、芸術的な弾幕パターンが特徴です。

## ゲーム概要

あなたは最新鋭の宇宙戦艦の艦長となり、未知の宇宙空間を航行します。
次々と襲いかかる敵の攻撃を避け、巨大な旗艦との遭遇を生き延びてください。

### 特徴

- **スタイリッシュなSFビジュアル**: ポリゴンで描かれた宇宙戦艦と、ネオンカラーの弾幕、そしてパララックス効果による疾走感のある背景。
- **巨大戦艦との遭遇（ボス戦）**: 航行距離に応じて出現する巨大な敵旗艦「ドレッドノート級」。画面を覆いつくす特殊弾幕を耐え抜きましょう。
- **芸術的な弾幕**: スパイラル、バイナリストリーム、ソーラーフレアなど、数学的な美しさを持つ多様な攻撃パターン。
- **パワーアップアイテム**:
    - **S (Shield)**: 船体を守る電磁シールドを展開（1回だけ被弾を防ぎます）。
    - **T (Time Slow)**: 局所的な時間の流れを遅くし、複雑な弾幕の回避を容易にします。
- **レスポンシブ対応**: PCのマウス操作、スマートフォンのタッチ操作の両方に最適化されています。

## 遊び方

1. [GitHub PagesのURL] にアクセスします。
2. **IGNITION** ボタンを押してゲーム開始！
3. **操作**:
   - **PC**: マウスを動かすと戦艦が追従します。
   - **スマホ**: 画面をスライドして戦艦を動かします。
4. **目標**: 敵の弾を避けながら、より遠くの宇宙（LY：光年）を目指してください。

## 技術スタック

- HTML5 (Canvas API)
- CSS3 (Custom Properties, Animations)
- JavaScript (ES6+, Vanilla JS)
